# VibeCoding

AI / VibeCoding 作品展示与分享平台。

汇集用 Cursor 等 AI 工具创作的项目，支持浏览、搜索、人气排行，以及登录后的点赞、收藏、评论与发布。

## 技术栈

- **前端**：Vue 3、Vite、OpenTiny、vue-i18n（中 / 英 / 日 / 韩）
- **后端**：Python 3.11、FastAPI、Tortoise ORM、MySQL、JWT
- **其他**：华为云 OBS（封面）、SMTP（注册验证码）

## 目录

- `vibe-fronted/`：前端应用
- `vibe-backend/`：后端 API
